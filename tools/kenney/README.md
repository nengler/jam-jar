# Kenney sounds

Everything here is by Kenney (https://kenney.nl), released under Creative Commons Zero (CC0 1.0): free for any use, no
attribution required. `tools/make-assets.py` turns it into `assets/`.

- The `.wav` sounds come from the tse engine repo's games (`games/*/tools/kenney/`), already converted there to 22.05 kHz mono
  WAV. Each is named after its pack and its name there (`interface-sounds-glass-001.wav` is `glass_001` of Interface Sounds).
- `kenney-mini-square-mono.ttf` is `Other/Fonts/Kenney Mini Square Mono.ttf` of the Kenney Game Assets All-in-1 bundle (3.8.0).
- From the same bundle, all pixel art:
  - `ui-pixel-adventure-large-thick.png`: `UI assets/UI Pack - Pixel Adventure/Tilesheets/Large tiles/Thick outline/tilemap_packed.png`
    (the frames, the HUD slate and the ribbon).
  - `pattern-pack-pixel-grayscale.png`: `2D assets/Pattern Pack Pixel/Tilemap/tilemap_grayscale_packed.png` (the gingham).
  - `ui-pixel-pack-sheet.png`: `UI assets/UI Pixel Pack/Spritesheet/UIpackSheet_transparent.png` (the jar's glass).
  - `pixel-platformer-tiles.png`: `2D assets/Pixel Platformer/Tilemap/tilemap_packed.png` (the coin).
  - `explosion-pixel-0N.png`: `2D assets/Explosion Pack/PNG/Pixel explosion/pixelExplosion0N.png`.

The whole bundle (555 MB) is attached to this repo's `Assets` release; only what the game uses is copied here.
