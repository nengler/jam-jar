# Kenney sounds

These sounds are by Kenney (https://kenney.nl), released under Creative Commons Zero (CC0 1.0): free for any use, no attribution
required. They come from the tse engine repo's games (`games/*/tools/kenney/`), already converted there to 22.05 kHz mono WAV.
Each file is named after its pack and its name there (`interface-sounds-glass-001.wav` is `glass_001` of Interface Sounds).
`tools/make-assets.py` copies them into `assets/` under the names the game plays.
