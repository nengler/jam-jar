# Fluent Emoji

The fruit pictures are Microsoft's Fluent Emoji, 3D style (https://github.com/microsoft/fluentui-emoji), MIT licence (see
`LICENSE` here, which must ship with the game). Each file is `assets/<Name>/3D/<name>_3d.png` of that repository, 256 x 256.

There is no emoji for a Durian or a Pomegranate: the game uses the Pineapple and a hue-shifted Red Apple as stand-ins.
`tools/make-assets.py` crops and scales them into `assets/`.
